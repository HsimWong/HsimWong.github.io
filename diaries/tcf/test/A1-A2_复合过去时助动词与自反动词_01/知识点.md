# 复合过去式
- avoir：通常只有直接宾语（COD）放在过去分词前面时，过去分词才与 COD 配合。
  J’ai écrit les lettres.（COD 在后，不配合）
  Les lettres que j’ai écrites.（COD 在前，阴性复数配合）
- être：普通的 être 动词，过去分词通常与主语性数配合。
  Marie est arrivée.
  Ils sont partis.
- 自反动词：需要看自反代词 se 在句中是 COD 还是间接宾语。
  Elles se sont lavées.（se 是 COD，配合）
  Elles se sont parlé.（parler à quelqu’un，se 是间接宾语，不配合）
  Elles se sont lavé les mains.（COD les mains 在后，不配合）
所以可以先记成：avoir 看前置 COD；普通 être 动词看主语；自反动词再判断 COD。
