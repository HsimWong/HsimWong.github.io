## 原表纠错摘要

`réceptioniste → réceptionniste`；`parfoi → parfois`；`repa → repas`；`décè → la mort / mourir / décédé`（依词性）；`quelquechose → quelque chose`；`mettre sa bonnet → mettre son bonnet`；`électronménager → électroménager`；`ustensil → ustensile`；`pâper → râper`（依“擦碎”释义）；`méchanisien → mécanicien`；`assosiation → association`；`banlieu → banlieue`；`réelement → réellement`；`vétériere → vétérinaire`；`Montpelier → Montpellier`。

`restauration` 通常指餐饮业/餐饮服务或修复、恢复，不等于“旅游业”；旅游业通常说 *tourisme*。`miller` 不是“一千”，应为 *mille*（数词）或 *un millier*（约一千/一千个）。`cordon` 通常是绳带，腰带一般是 *ceinture*。`toboggan` 是滑梯，不是“滑动”。
