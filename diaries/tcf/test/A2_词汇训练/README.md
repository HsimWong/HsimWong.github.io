# 《你好法语 A2》词汇训练

词汇范围按教材单元逐步导入。每一轮小测都从你提供的真实词表中抽取，不用我猜测教材词目。

## 词条记录格式

每个新词至少记录：

| 法语词条 | 词性 / 阴阳性 | 中文义 | 固定搭配 / 例句 | 初测易错点 |
|---|---|---|---|---|
|  |  |  |  |  |

- 名词：记 **un/une + 名词**，包括阴阳性和复数形式（不规则时）。
- 动词：记不定式、常用介词或宾语结构及固定搭配，例如 `dépendre de`。如适用，补充过去分词/常见变位。
- 形容词：记阴性、复数变化和常见搭配。
- 固定表达：整块记忆，不拆成单词翻译；在例句中练习使用。

## 每轮复习与小测

1. 导入一个教材单元或主题的词表，控制在约 15–25 个新词。
2. 我先出不带答案的试卷，包含法中/中法提取、听写式拼写、名词阴阳性和固定搭配填空/造句。
3. 你提交答案后，我逐项批改并说明错误属于拼写、词性/阴阳性、搭配还是语境使用。
4. 错词进入错词区，并在下一次、隔天、约三天后和一周后混合复测。
5. 词汇只有在延迟复测能正确拼写、记对阴阳性、写出搭配并能造出合适句子后，才在总追踪表打勾。
