# 未完成过去时专项卷 01｜L’imparfait

**目标：**检查未完成过去时的变位、基本使用场景，以及它与复合过去时的区别。建议先独立完成，不查笔记；不确定的题可标“猜”。可分部分发送答案。

## A. 变位规则

### 1. 写出词干和六个人称变位

| 不定式 | 词干 | je | tu | il/elle/on | nous | vous | ils/elles |
|---|---|---|---|---|---|---|---|
| parler |  |  |  |  |  |  |  |
| finir |  |  |  |  |  |  |  |
| prendre |  |  |  |  |  |  |  |
| être |  |  |  |  |  |  |  |

### 2. 填入正确变位

5. Quand j’étais enfant, je __________ souvent chez ma grand-mère. *(aller)*
6. Nous __________ dans un petit appartement. *(habiter)*
7. Vous __________ toujours très tôt. *(se lever)*
8. Les enfants __________ beaucoup de bruit. *(faire)*
9. Tu __________ un livre quand je suis arrivé. *(lire)*
10. Il __________ froid et il __________. *(faire / pleuvoir)*
11. Elles __________ très contentes de nous voir. *(être)*
12. Je __________ cette chanson par cœur. *(connaître)*

## B. 选择时态：imparfait 还是 passé composé

把括号里的动词变成合适的过去时。需要时，同一句中可能用到两种时态。

13. Hier, il __________ quand nous __________ de la maison. *(pleuvoir / sortir)*
14. Quand elle __________ petite, elle __________ peur des chiens. *(être / avoir)*
15. Je __________ la vaisselle quand le téléphone __________. *(faire / sonner)*
16. Tous les dimanches, nous __________ nos grands-parents. *(visiter)*
17. Soudain, quelqu’un __________ à la porte. *(frapper)*
18. À cette époque, mon père __________ dans une banque. *(travailler)*
19. Pendant que vous __________, le train __________. *(dormir / partir)*
20. L’année dernière, ils __________ à Québec pendant deux semaines. *(rester)*

## C. 判断语境与理由

每题选择 **imparfait** 或 **passé composé**，并用中文简要说明理由（背景/状态/习惯/持续动作，或完成的具体事件）。

21. *La rue était calme.*
22. *Tout à coup, une voiture est passée.*
23. *Chaque été, on allait à la mer.*
24. *Elle a ouvert la fenêtre.*
25. *Je cherchais mes clés quand tu m’as appelé.*

## D. 找错并改正

每句有一处与时态有关的错误。改写整句。

26. *Quand j’ai été petit, je jouais au parc tous les jours.*
27. *Il faisait beau quand soudain, nous regardions un éclair.*
28. *Elle lisait un roman, puis elle s’endormait immédiatement.*（按“她读完后就睡着了”的意思改写。）
29. *Nous étions en train de dîner quand Marie arrivait.*（表达“玛丽到了”这一突然发生的事件。）

## E. 自己组织表达

30. 写两句描述你小时候的生活，至少用两个 imparfait 动词。
31. 写一句以过去背景开头、再写一个突然发生的事件。至少使用一个 imparfait 和一个 passé composé。
32. 用法语完成：**Quand j’étais…, je…**（可以写真实经历或合理编造。）

## F. 口头小任务（可选但推荐）

不预先写稿，用法语说 30–45 秒：**Racontez une journée de votre enfance.** 描述当时的生活或习惯，再说一件具体发生的事。可以发录音，或发你说话的转写稿。
