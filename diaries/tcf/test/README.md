# 测验资料夹使用规则

## 专题索引

- [A1–B1 直陈式现在时：第二组与第三组不规则动词](A1-B1_直陈式现在时_第二组与第三组不规则动词_01/词汇表.md)
  - [考卷 01（动词 01–20）](A1-B1_直陈式现在时_第二组与第三组不规则动词_01/考卷01.md)
  - [考卷 02（动词 21–40）](A1-B1_直陈式现在时_第二组与第三组不规则动词_01/考卷02.md)
  - [答案与批改标准](A1-B1_直陈式现在时_第二组与第三组不规则动词_01/答案与批改标准.md)

- 每份考卷单独放在按知识点命名的资料夹中，命名格式：`阶段_知识点_序号`，例如 `A1-A2_综合诊断_01`、`A2_条件式现在时_01`。
- 每个资料夹至少包含 `考卷.md` 和 `答案与批改标准.md`。发给你作答时先用考卷；答案文件留作核对和讲解依据。
- 每次批改后，按实际表现更新上一级的 `知识点追踪.md`；尚未复测的项目保持未勾选。
- 词汇测验放在 `A2_词汇训练` 内，按教材课次/主题继续建立子文件夹；每份同样保存考卷和答案/评分记录。
- 词汇范围来自你提供的《你好法语 A2》词表或清晰页面照片，并同时检查拼写、名词阴阳性和固定搭配/表达。错词进入之后的延迟复测。
